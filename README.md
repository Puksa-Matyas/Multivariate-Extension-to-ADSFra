# M-ADSFra
M-ADSFra is a version of ADSFra with support for multivariate time series data. New benchmarking datasets, fingerprinting and anaomyl detection algorithms.

### Datasets
The framework is tested with the following datasets: SMD, SMAP, MSL. These datasets can be downloaded from the following links:
-SMAP & MSL: [text](https://www.kaggle.com/datasets/patrickfleith/nasa-anomaly-detection-dataset-smap-msl)
-SMD: [text](https://www.kaggle.com/datasets/mgusat/smd-onmiad)
Note that SMAP and MSL requires preprocesing.
